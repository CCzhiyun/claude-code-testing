# 长会话、上下文、导出与回退（0.40）

0.40 在每轮请求前按“完整输入估算 + 输出预留 + 安全预留”计算占用：达到 90% 提醒，严格超过 95% 且 Auto compact 开启时自动压缩。不是累计账单 token。新协议与验证见 [0.40 接入说明](AZURE-RESPONSES-0.40.zh-CN.md)。

0.39 新增本地/服务端超限的有界自动恢复、可编辑 token 上限及恢复记录。配置、测试和不能自动恢复的情况见 [0.39 验收说明](RELEASE-0.39.zh-CN.md)。

## 一条完整链路

1. Agent 组装系统指令、Skills、记忆、仓库资料和工具定义。
2. 根据配置窗口扣除输出预算和安全预留，再决定聊天历史可用空间。
3. 自动压缩按完整用户轮次归档，保留最新用户轮次及其工具调用/结果；Settings 的 Auto compact 开关控制自动压缩。
4. 每次准备请求时保存仅含计数的上下文快照，`/context` 展示分项估算、输出预留、安全预留和余量。
5. `/compact` 可主动压缩完整旧轮次；完整原始历史保留，`/export` 可以导出。
6. 新检查点保存独立的会话快照，压缩后也可恢复对应消息、归档和摘要。TUI 回退后重新附着恢复的会话。

## 可直接使用

```text
/context
/compact
/export conversation.md
/export conversation.json
```

不进入交互界面也可运行：

```cmd
ccpt sessions context SESSION_ID
ccpt sessions compact SESSION_ID
ccpt sessions export SESSION_ID conversation.json
```

导出包含已归档历史、不重复人工生成的摘要；省略推理块及图片载荷，不覆盖已有文件，并检查工作区与受保护路径。分享前仍须检查正文中的业务敏感信息；导出不是脱敏服务。

## 边界

- 计数仍是模型无关估算，不是服务端 tokenizer 或计费。`/context` 区分快照、当前消息估算和服务端报告输入；快照也可能对应本地拒绝/失败的准备请求。
- 压缩摘要是有上限的原文摘录，不是模型生成的完整语义摘要。原文在归档中，但未全部发送给模型。
- 最新单轮输入、工具结果或固定上下文过大时明确失败，不会悄悄切掉工具结果。需要减小输入、减少工具/插件或选择模型实际支持的更大窗口。
- 不在运行中、排队中或等待问题回答时执行会话压缩、重命名和会话回退；先完成输入或停止 Agent。该交互检查不是跨所有进程写入的数据库事务。
- 新检查点使用内容寻址快照，保留最近 100 个；工具调用尚未返回时创建的检查点将会话定位到该未完成批次之前，防止恢复孤立调用。
- 旧检查点只有消息数，无法可靠恢复已压缩会话时会拒绝会话回退，仍可显式选择仅恢复代码。
- 代码回退与会话落盘不是跨文件原子事务；操作系统写入失败时可能需要人工恢复。

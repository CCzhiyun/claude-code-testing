# 0.46：可选语义摘要与上下文连续性

日期：2026-09-29。本轮补齐上下文质量中的“模型语义摘要”可选路径，不声称完成所有企业验收。

## 开启方法

在用户或项目 settings.json 加入（保留现有 model、network 等配置）：

```json
{
  "ui": { "autoCompact": true },
  "contextCompaction": {
    "mode": "semantic",
    "maxInputTokens": 32000,
    "maxOutputTokens": 1500,
    "timeoutMs": 30000
  }
}
```

也可以打开 `/config`，搜索 `Automatic summary mode`，切换后保存。`extractive` 为默认值，不额外调用模型。`semantic` 显式允许付费摘要调用；沿用当前三协议之一、模型部署、认证、CA、代理、网络策略及预算，不另配外部摘要服务。

`maxInputTokens` 和 `maxOutputTokens` 为估算上限，不是精确 tokenizer 或计费承诺。摘要输出还会受当前模型输出上限、现有摘要空间限制；输入不得超出当前模型扣除预留后的容量。正文过大直接回退，不截掉一半后冒充完整语义摘要。本版尚未实现分块递归摘要。

## 实际执行顺序

1. 占用达到 90% 时提醒，严格超过 95% 且启用 autoCompact 时压缩；占用包含输入估算及输出/安全预留。
2. 按完整用户轮次归档旧消息，保留最新用户输入及其工具调用/结果；先持久化本地摘录检查点。
3. 语义模式将上一份摘要与本次新归档轮次作为待总结数据，要求保留目标、约束、已确认决策、改动路径、测试结果和待办。图像内容、思考文本和 Responses 内部状态不传给摘要请求。
4. 不提供任何工具；不执行摘要里的指令；关闭推理、fast、Responses 存储和结构化输出约束。摘要请求自身不重试，且有总时限。
5. 接受非空、未截断、没有工具调用、满足大小约束的摘要；明确标为可能遗漏信息的模型生成交接记录，保存后才继续主请求。
6. 保持同一个会话继续回答，全文仍可 `/export`。取消期间已经保存的本地归档仍可恢复；取消不会继续发主模型请求。

提供方明确报上下文超限时的有界恢复路径也可使用语义摘要；原有最多两次恢复重试限制不变。因此一次主请求若连续触发不同压缩阶段，可能产生多次摘要调用，但不会无限循环。部分回答已输出后仍不会自动重放。

## 失败与可观测性

- 输入太大、输出无效/截断、HTTP 错误、超时：保留本地摘录，记录 `input-limit` / `invalid-summary` / `request-failed` / `timeout`，继续已有恢复流程；不保存原始服务端错误 body。
- 用户取消：传播取消信号，不将取消伪装成成功摘要。
- 预算耗尽：停止后续付费请求，不通过摘要绕过会话预算。
- 归档写入失败：不发送摘要请求。摘要保存失败：不继续主请求。
- `/context` 显示上次摘要方式；`ccpt sessions context <id>` 输出摘要元数据。
- 已返回响应的摘要调用记入 `/usage`，分类 Agent 为 `context-compaction`，区分报告/估算 token；配置金额预算时沿用预算账本。失败/取消未返回 usage 的请求可能仍收费，不能据此认定零费用。

只对已知环境凭据、配置的认证变量及部分常见秘密格式做尽力脱敏；这不是完整 DLP。摘要输入仍包含对话与工具输出中的业务信息，会发送给当前部署。启用前应确认公司的数据政策。全文归档仍包含原始内容，应按原有会话存储政策保护。

## 手动压缩与默认兼容性

`/compact` 和 `ccpt sessions compact <id>` 本轮仍是本地摘录压缩，不因打开语义模式而暗中付费。语义模式仅用于 Agent 自动阈值压缩及上下文超限恢复。关闭 autoCompact 时不会触发自动摘要。首次安装默认仍是本地摘录，不改变模型、协议或公司配置。

## 本地验证与仍未完成项

新增测试覆盖三种协议的摘要请求、无工具/无 Responses 存储、归档和最新工具轮次完整性、已知凭据脱敏、单次用量记录、超时、取消、输出截断、输入限制、写盘先后顺序、预算限制，以及真实终端/Agent 路径中压缩后读文件和续聊。提供方由本地测试服务器模拟，不是公司生产环境或摘要语义质量基准。

仍未关闭：真实 tokenizer、多模态精确计数、自动摘要质量评测、1M / 大型仓库基准、超大历史的分块摘要。模型摘要可能产生遗漏或事实错误，不承诺零信息损失。

其他企业事项仍按 [剩余清单](REMAINING-0.41.zh-CN.md) 跟踪：OS 沙箱与逃逸矩阵、专用凭据后端、许可/NOTICE/重分发授权、公司 CA/代理/mTLS/Entra 真机矩阵、MCP 常驻 SSE/OAuth 全流程、跨 worktree 冲突向导、生产插件和 IDE 互操作等，没有因本次发布自动标成完成。

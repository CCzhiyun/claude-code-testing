# CCPT 0.38 审批、预览和拒绝记录

## 开启需要的审批规则

本次不擅自修改用户默认权限。希望写文件、运行命令前确认，可在 `/permissions` 的 Ask 页签添加规则，或在项目 settings 中加入：

```json
{
  "policy": {
    "permissionRules": { "ask": ["write_file(*)", "run_command(*)", "shell_start(*)"] }
  }
}
```

Ask 是额外的确认，不会绕过命令白名单、路径保护、restricted、sandbox wrapper 或托管 Deny 规则。Accept edits 模式沿用原语义：跳过编辑类 Ask，不跳过 Deny。

## 真实工具审批

命中 Ask 后 Agent 暂停，打开审批选择器。`write_file` 展示读取当前文件后生成的有界替换片段，其他工具展示参数 JSON。↑/↓ 或数字选择，Enter 确认；PageUp/PageDown 滚动预览。Esc 仅关闭面板，不批准、不拒绝、不启动模型；`/questions` 可重新打开。

- **仅本次**：授权绑定完整工具参数的哈希，包括写入内容及命令参数数组。参数变化须重新批准；跨进程文件锁确保最多消费一次，默认 5 分钟过期。
- **本会话**：允许同会话、同工具、同 subject 的后续调用；同一路径允许不同写入内容。不是只允许预览里的内容，需谨慎选择。最多 10,000 次、默认 12 小时，不跨 session。
- **拒绝**：同会话、同工具、同 subject 的重试在工具执行层拒绝，默认保留 12 小时，而不只是提醒模型不要重试。

`subject` 是目标摘要：文件路径、命令文本、MCP server/tool 等，不是整个工作区授权。模型使用其他路径拼写或其他工具时仍按各自规则判断；这不是通用的操作系统隔离。

`/permissions reset` 清除当前会话的临时允许及用户拒绝记录，保留项目/管理员规则。运行中的前台 Agent 须先停止。临时记录最多保留 256 条，较旧记录可能提前淘汰；升级前旧格式的临时授权失效，需重新确认。

## 最近拒绝与托管策略

- `/permissions recent`：按当前工作目录查看用户拒绝和显式 Deny 规则拒绝；Ctrl+R 刷新，`/` 搜索，只读。
- `ccpt permissions recent`：输出同一记录供终端脚本使用。
- 记录最多保留最近 200 条（用户状态目录总量），尽力隐藏凭据；它不覆盖所有 OS/沙箱/网络层错误，也不替代企业审计服务。
- 管理员控制的权限页签显示只读提示；TUI 设置、模式命令和 Shift+Tab 不能覆盖托管权限模式。其他配置面板不因此成为完整的策略来源浏览器。

临时授权文件不再保存完整 input、文件内容或预览；保存 scope 哈希及一次性参数哈希。原始会话本身仍包含正常的工具调用历史，不是脱敏存储。

## 预览边界与验证

预览读取服从路径与敏感文件规则；二进制或超过 256 KB 的内容显示“未预览”。每侧最多显示 60 个变化行、每行最多 500 字符，不是完整 Git diff。文件可能在等待审批时被外部程序更改；本次没有实现跨文件事务或旧文件内容的 compare-and-swap 锁定。

自动化验证真实写文件、一次性/会话授权、模型拒绝后重试、取消重开、历史查询、权限重置、并发授权消费和配置优先级。未宣称所有命令、所有 MCP、系统级沙箱和多 Agent 审批的完整企业验收已经完成。

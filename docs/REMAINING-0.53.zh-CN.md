## 代码/产品能力尚未实现

1. **自动化**：CLI 全退出后的 OS 常驻/定时启动；损坏状态的自动修复与安全重试中心。现有 doctor 只诊断，投递仍发生在下一次授权 session/worker 回合，不自动重放副作用。
2. **IDE/Teams**：bridge 自动重连与失联期间通知补发；TUI 新增成员/Plan 的全量列表自动重载（已有项会更新，新项用 r）。审批订阅、过期拒绝和真实双 bridge 竞争已有实现。
3. **Skills/Hooks**：全部参照事件 payload/退出码完全等价、全部自动触发点、跨进程 once、动态 shell 插值；用户全局/自定义目录的自动热更新。本版只有明确开启的本项目有界 watch，不承诺任意插件零停顿热替换。
4. **插件**：独立签名/授权的 Marketplace overlay 合并、跨多个插件/来源收据的原子回滚、写 journal 前残留的自动恢复。首次安装和替换的合法 journal 现已能显式恢复；没有通过重写签名 manifest 冒认 overlay 来源。
5. **MCP**：Agent/TUI 内嵌套人工审批、独立 GET SSE 的反向交互、URL elicitation、多模态 sampling、POST 自动断线续传。现有 stdio/POST 子集已有阶段审计和传输回执，但审计日志未做外部防篡改签名/集中审计存储。
6. **凭据**：macOS/Linux 专用模型凭据后端、独立凭据进程/硬件隔离。Windows DPAPI 和前后台 worker 接入、端点绑定及脱敏导出已经实现，不在此缺口内。
7. **Git**：二进制/删除冲突的完整可视化解决器、自动选择 ours/theirs、恢复 ref 自动保留期/跨机器备份。当前支持人工编辑后的安全校验/暂存、分页与有明确保留分支的单 ref CAS 清理；没有自动删除唯一恢复引用。

- 实际 VS Code 多窗口、Remote/多根工作区、断线恢复和升级矩阵；现有双 bridge/16 竞争与核心 64 路 CAS 不是 GUI 全认证。
- 插件/任务/会话的真实断电、损坏磁盘、网络文件系统与跨多个文件原子事务；外部副作用 exactly-once 不承诺。
- 真实第三方团队插件、MCP 企业服务器互操作和长期压力。SDK/CLI fixtures 不代替这些环境。

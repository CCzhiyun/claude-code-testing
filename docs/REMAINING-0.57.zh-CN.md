## 当前范围的技术边界

- Windows uninstall 仅在读取时核对指定任务动作和主体；不声称能抵御同用户恶意并发更换任务的所有竞态，不是 OS 沙箱。查询失败先保留本地停用，不自动强删。
- rebind 是新 ID 的显式迁移流程，不是跨 OS 注册表/两份文件的原子事务；中断后检查 list/status 再继续。已安装 OS 动作存在时，不擅自覆盖。
- 通知最多 500 条；状态先持久化、通知后尽力写入，极端断电可能缺一条通知。不是事务 outbox、不可篡改审计或完整事件流。
- 元数据日志仍最多 1024 条；过旧游标重建快照，不将历史失效视为权限。部分变更依赖监听回退。
- 全局撤销时，已加载视图可能保留旧内容并显示重载失败；后续 worker 加载重新验证授权。强制隔离/终止已运行扩展属于后续安全工程。

## 已补领域仍然存在的边界

- 自动化：缺完整 Coding/测试/提交 Goal 引擎、人工审批后的自动续行、完整原会话继承、外部副作用幂等键/结果查询/连接器补偿。Goal 暂停不等于取消运行中 Agent。调度重绑后旧 job 队列不自动迁移，需人工核验后新建。
- 会话与 IDE：正文是每条 2000 字符有界脱敏预览，不是完整工具/推理/图片或 provider 状态导出。运行历史保留 512 条元数据，不是精确流式重放/无损 outbox/集中防篡改审计；没有承诺消除断电窗口。桥接仍以串行请求为主，不是完整并发运行/取消协议。
- Hooks：本轮接入列出的内置路径，不是任意 shell/外部编辑器的全文件监听。MessageDisplay、CwdChanged、全部指令加载源/生命周期触发点与逐事件参照 payload/退出码、任意插件零停顿替换和 exactly-once 仍缺。全局授权撤销不强杀已运行插件。
- Plan/Teams：真实 VS Code Remote、多窗口/多根、跨 OS 升级/长期断线/网络文件系统矩阵未验收。模拟 VS Code host 不代表真实 IDE 认证。

## 后续平台工作（本版没有冒称完成）

1. 插件：独立签名 Marketplace overlay、跨插件/收据原子回滚、真实团队插件矩阵、中断来源核验。
2. MCP：独立 GET 反向人工交互、嵌套审批、URL/多模态、POST 自动续传、集中防篡改审计、企业服务器互操作。A2 连接器恢复不是这些能力的替代。
3. 凭据：macOS/Linux 专用后端、独立凭据进程/硬件隔离。
4. Git/搜索：ref 自动保留期/自动远程备份、二进制/删除冲突完整解决器、真实大仓性能矩阵。
5. 企业执行安全：OS 沙箱与恶意进程树/逃逸测试；restricted/白名单/NoNewPrivileges 不能替代。
6. 公司接入：真实 Azure 部署、公司 CA 链/代理/mTLS/Entra 续期与后台 worker 实机矩阵。
7. 上下文质量：真实 tokenizer/多模态精确计数、语义摘要/1M 大仓质量基准；不承诺零信息损失。
8. 发布：第三方真实来源权利、许可/NOTICE/重分发批准、旧品牌兼容层整理；UNLICENSED 与改名不产生授权。
9. 真实 push/PR、真实 IDE/OS 升级与长期故障恢复仅能在明确范围/授权和目标环境中验收。

本版优先补 A1–H4 的可验证代码缺口，未继续扩大到上述其他领域，避免把已有未验收能力与新功能叠加后统称完成。

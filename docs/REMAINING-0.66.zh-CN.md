# 0.66 剩余与验收边界

本批补旧未绑定 context-only scheduler 的显式迁移、目录 FileChanged 观察和 split-index 冲突。沿用 A1–H4 与原平台领域，不换分母、不宣称剩余全完成或精确三分之一生产验收。

| 领域 | 仍缺代码/产品能力 | 尚未完成的目标验收 |
| --- | --- | --- |
| A1–A4 | 通用业务幂等/连接器补偿；付费/上传旧任务不自动迁移审批；迁移 preparing 未知状态需人工核验；manager/本地文件不是全局事务 | OS/发行版/GUI/企业策略、中断/长期断电；真实任务未注册 |
| P1–P4 | 只有 Plan/通知为提交后 outbox；其余生产者、无限历史、精确 delta/图片/provider 重放；Markdown/index 非跨文件事务 | Remote/多窗口/多根/升级/NFS |
| H1–H4 | 有界目录轮询已补，仍非全参照事件触发/决策/退出码一致；短暂变化捕获/强实时撤权/零停顿插件替换/exactly-once 不保证 | 企业 Hook/Skills/插件互操作与长时间文件变更矩阵 |
| 插件 | 旧单插件历史迁移、后台更新/分发策略；不完整/不可信中断不自动采用 | 团队密钥/真实源站、跨机/NFS/中断 |
| MCP/审计 | 现代 sampling 工具执行为显式 SDK，非内置通用预算 UI；可选协议扩展；checkpoint 非集中正文归档/WORM/硬件隔离 | 企业服务/OAuth/反向交互/代理/媒体、独立 collector 部署 |
| 凭据/OS | 独立身份/硬件隔离、Windows/macOS 完整沙箱/逃逸防护 | 原生凭据/headless、恶意进程树/安全评估 |
| Git/搜索 | split-index 常规 blob 冲突已补；symlink/submodule、多文件可视合并、一键完整 split 备份恢复；更多远端/SSH与自定义 Hooks/wrapper 无人值守备份 | SHA-1/SHA-256/index v2–v4 本地用例不等于真实大仓/跨机/NFS；业务 push/PR 未执行 |
| 公司接入 | 私有部署差异须真实响应适配 | Azure/CA轮换/代理/mTLS/Entra/worker；公司请求0 |
| 上下文质量 | 私有词表/framing/多模态精确 token、1M仓库/摘要质量，不承诺无损 | 目标模型/真实企业数据集 |
| 发布/来源 | 兼容旧品牌不能抹除原始法律声明或破坏协议 | 真实来源权利、NOTICE/再分发批准、真实 OS/IDE 升级、长期故障；UNLICENSED/改名/本地安装不产生授权，新 inventory 不沿用旧批准 |

候选包仅供本地所有者验证。未自动更改个人配置、实际全局安装，未请求公司服务、发布 registry 或执行业务 push/PR。其余先前版本的详细边界继续保留。

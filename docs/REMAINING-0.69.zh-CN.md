# 0.69 未完成与目标环境验收

本清单沿用原 A1–H4 和平台领域，不改变分母，不把本地模拟通过写成全平台完成。准确构建、测试、安装结果见交付包旁的 VALIDATION 与 evidence。

## 本批已补的代码

1. A2：连接器显式业务字段/部署摘要绑定的幂等键；跨调用、Agent、会话重复拒绝，人工核验 not_applied 后允许新 claim。不能代替服务器幂等协议或跨系统事务。
2. P3：显式选择 metadata、redacted 或需明文风险确认的 verbatim 活动日志；分页、完整性链、丢失索引恢复、容量/写入失败缺口、CLI/TUI/IDE 被动读取。隐藏推理从不捕获；无持久化运行不新增日志。
3. 插件：精确版本渠道、可信签名、审批摘要/过期/CAS、代际激活和未知结果核对；旧激活入口不能绕过策略；策略模式不自动下载或激活。
4. Git：企业 launcher 声明的本地依赖文件/目录递归摘要绑定，依赖变化后旧审批失效；不是自动发现全部 OS 依赖。
5. 上下文：私有 BPE 的自定义预切分正则、特殊 token 模式、无模型凭据子进程与硬超时；本地 1M 文本计数基准。90% 提醒/95% 压缩沿用，不关闭对话。
6. 公司接入：显式付费且带预算的真实接入验收命令，包含多轮、完整工具列表、实际受策略控制的 read_file、工具结果回传、流式和取消。默认不触达公司环境。
7. MCP：经预算、交互、本次选择和模型配置显式启用的 WAV/MP3 Chat 音频输入；Responses 不支持的输入提前拒绝，不偷偷切 endpoint。
8. 权限：旧 Read/Edit/Bash 等 ask/deny 规则保守映射到实际工具；不扩大 allow，多文件 patch 采用保守拦截。

## 本版不承诺的性质

任意外部业务 exactly-once、无限日志、跨 OS/远端全局事务、任意插件零停顿热替换、恶意同 OS 身份管理员隔离、摘要零信息损失都不是单个配置开关能实现的保证。已有代码采用限额、显式审批、摘要绑定、保守拒绝与 unknown 人工核对，失败不隐瞒，不删除会话，不自动换公司 endpoint。

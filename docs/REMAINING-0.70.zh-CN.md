本轮不换分母，不称“三个领域全部生产完成”。代码、自动化/实际 Node 验证、目标公司环境分别记录。完整数字在随包 VALIDATION/evidence。

| --- | --- | --- |
| MCP transport | SSE retry 控制帧、POST 的 GET-only 续传有界重连/等待取消、独立 GET 遵守服务端间隔 | 长期断网、真实企业代理/网关/各服务器流实现矩阵；断线不能保证远端工具没执行，不会自动重发工具 POST。 |

## 原 A1–H4 与其他平台缺口继续保留

本轮只优先上述三个领域，没有把其他项目静默清零。[0.69 完整对照](REMAINING-0.69.zh-CN.md) 的 A1/A2 真实业务完成/补偿契约、A3/A4 跨 OS 原生调度/升级/断电、P1–P4 全局事务事件/完整 UI 状态/Remote 多窗口/NFS、H1–H4 全事件/决策/退出码兼容和无停顿热替换等边界继续适用。

Windows/macOS 完整 OS 沙箱、独立身份/硬件隔离、复杂 Git 图形冲突、其他系统凭据真机、公司 Azure/CA/代理/mTLS/Entra/worker 实机、真实业务 push/PR 与法律发布材料也仍需分别实施/验收，未被本轮测试替代。

未执行公司 API、未使用个人模型 Key、未把普通文件宣称 WORM、未伪造来源授权或删除必要署名。最终包仍为所有者本地验证包；团队/registry 分发必须先通过真实权利审阅与新 inventory digest 审批。

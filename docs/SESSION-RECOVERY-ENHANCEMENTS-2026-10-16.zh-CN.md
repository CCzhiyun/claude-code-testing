## 新行为

- `ccpt --resume` / `ccpt -r`：在交互式终端打开选择器；非交互输入明确报错，不偷偷发起模型请求。
- `ccpt --resume "项目名称"`：按当前工作目录内的完整名称恢复。唯一匹配直接恢复；同名多个会话时，交互启动打开带搜索词的选择器，print 模式明确报错。
- `/resume 名称`：支持含空格的完整名称；不做模糊自动选择。重名时提示打开选择器或使用 ID。
- `/continue` 是 `/resume` 的别名；`/fork` 是 `/branch` 的别名，且别名进入命令补全，避免被相似命令误替换。
- `/branch 名称`：只创建并切换分叉，显示原会话和新会话 ID。名称不再作为提示提交给模型。
- `/clear 名称`：命名正在离开的会话后清空当前对话；命名失败时不清空。`/new`、`/reset` 是别名。
- 原会话、工具调用记录、压缩归档均保留；预览/命名/分叉不执行模型、工具或历史命令。

## 选择器快捷键

| 操作 | 按键 |
| --- | --- |
| 移动 | ↑ / ↓、j / k、PageUp / PageDown、Home / End |
| 恢复 | Enter；未进入搜索/预览时使用 1–9 |
| 预览 | Space；搜索中使用 Ctrl+V，终端可能将其截获为粘贴 |
| 重命名 | Ctrl+R；Enter 保存，Esc 取消，Ctrl+U 清空 |
| 搜索 | `/` 或普通文字；搜索中的 j/k、数字、空格按文字处理 |
| 范围 | Ctrl+A 切换当前项目/所有项目 |
| 刷新 | Ctrl+L；其他资源面板仍使用 Ctrl+R |
| 返回 | Esc 按预览、搜索、选择器分层退出 |

预览最多最近 40 条消息，每条最多 1200 字符；不显示隐藏推理、图片原始数据和工具输入对象。
重命名和搜索支持组合 emoji 的完整退格；名称拒绝控制字符、空名称及超过 120 字符。
保存名称时保持同一个目标高亮，异步保存/恢复期间防止重复按键触发多次操作。

## 安全与差异

- 仍然禁止把其他工作目录的会话直接绑定到当前目录执行，不因名称恢复或全项目浏览绕过工作区边界。
- 正在运行或等待审批的会话不会被重新启动第二个 worker，重命名也不会覆盖其状态；完整后台接管尚未实现。
- 同仓库多 worktree 识别、分支筛选、PR URL 筛选、分组、JSONL 路径导入尚未实现。
- 完整恢复模型/Agent 身份/Plan/权限/自动化状态仍需独立的持久化和恢复协议；本次没有声称完成。
- 不自动修改用户 settings、API Key、CA，也没有发布 npm 或覆盖全局安装。

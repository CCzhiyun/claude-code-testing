# 0.48 Windows 终端对比记录

日期：2026-10-05。本次重新启动本机参照 CLI 2.1.153（`--bare`）与构建后的 CCPT 0.48.0，通过 PTY 实际发送按键。未发送公司或 GLM 模型请求；不是所有功能或插件的完整对比。

| 入口 | 观察与本版处理 |
|---|---|
| 启动 | 双方显示版本、当前模型、工作目录与提示；本项目保留自己的 CCPT 品牌及边框。均沿用原配置，不切换模型。 |
| `/config` | 双方有搜索与分类页、Space 暂存、Enter 保存和分层 Esc；在本项目实际搜索到新增的 MCP credential storage。取消未保存草稿。 |
| `/model` | 双方提供当前/default 模型、左右调 effort、默认/仅本会话选项和 Esc；候选名称来自各自配置，不能为了看起来一致而替换真实部署。 |
| `/mcp` | 当前工作区双方都显示无服务器配置。带服务器的 CCPT 场景通过真实输入驱动测试覆盖 Configured/Listeners、详情、通知查看与停止确认；未宣称此步骤连接了公司服务器。 |
| `/tasks` | 参照当前空后台列表；本项目 Running/History/Todos 分类、搜索/刷新，新增 MCP 监听记录及详情停止入口。 |
| 启动续接与自动化 | 参照 help 包含 continue/resume、tools default/空列表、budget、effort。本版补相应入口，实际 CLI/worker 测试覆盖历史传递及工具配置；事件格式仍不完全等价。 |

`--bare` 是最小参考模式，不代表参照在安装全部插件后的行为。本项目插件数量、权限和菜单会受自身团队配置影响；没有把菜单存在视为插件完整互操作。

其他仍未对齐：全菜单像素级行为、不同终端/输入法/滚动和设备矩阵、语音/浏览器/移动产品、远程 IDE 矩阵。安全、企业和协议剩余项见 [当前清单](REMAINING-0.48.zh-CN.md)。

本次退出两个测试终端，未修改全局 npm 安装、密钥、CA 或默认模型，未执行 push/PR、公开发布。
